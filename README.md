# 山脊冲刺 · Ridge Run

一款单文件、纯前端的无尽爬坡小游戏。驾驶越野车沿山脊一路向上，在燃油耗尽前冲得更远。

**在线试玩：** https://dcjaychou-design.github.io/Ridge-Run/

## 玩法

- 控制油门与刹车，越过起伏的山脊，稳住车身
- 沿途收集金币；拾取油桶补充燃油
- 腾空时间越长，飞跃等级越高；落地可获得金币奖励
- 翻车后回到起点重新出发，本程距离清零，金币与个人最佳保留
- 燃油见底即结束本程；金币余额与个人最佳保存在浏览器本地

## 操作

| 按键 | 动作 |
| --- | --- |
| `D` / `→` / `Space` | 油门 |
| `A` / `←` | 刹车 / 倒车 |
| `P` | 暂停 |
| `M` | 静音 |
| 触屏 | 右侧油门 · 左侧刹车 · 腾空时用两只踏板控姿 |

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或在项目目录启动一个静态服务器：

```sh
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术

单文件 HTML + CSS + 原生 JavaScript，场景使用 Canvas 2D 绘制，无任何构建步骤与运行时依赖（仅从 Google Fonts 加载字体）。金币余额与个人最佳成绩通过 `localStorage` 记录。
