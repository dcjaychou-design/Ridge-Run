# 山脊冲刺 · Ridge Run

一款纯前端的无尽爬坡小游戏。驾驶山脊载具一路向上，在燃油耗尽前冲得更远；用空翻、完美落地和单轮平衡积攒氮气，穿过晨雾松林、高寒冰川、赤岩峡谷与极夜山巅；收集金币，回到车库解锁新车、升级四项性能。第四阶段加入 PB / 好友幽灵车同屏竞速、每日固定种子试炼、URL 战书挑战、单局悬赏微任务与 Canvas 战术战报，全部数据仍然只存在本地浏览器。

**在线试玩：** https://dcjaychou-design.github.io/Ridge-Run/

## 玩法

- 控制油门与刹车，越过起伏的山脊，稳住车身
- 沿途收集金币；拾取油桶补充燃油
- 腾空时间越长，飞跃等级越高；落地可获得金币奖励
- 完成 360° 空翻、贴坡完美落地、持续抬头单轮行驶，都能获得额外金币与氮气奖励
- 氮气加速会提升推力、极速和镜头视野；拾取涡轮气瓶可立即补充
- 每 500m 切换一个生态赛段，冰面会打滑，泥地会增加滚动阻力
- 拾取磁铁信标后，附近金币会自动飞向车身
- 腾空时同时按住两只踏板，可大幅稳定车身姿态；地面同时按下时刹车优先
- 翻车会立即结束本程并结算成绩，本程金币计入累计余额；按 `R` 可随时重新开始
- 燃油见底后若车辆停住或滑行超时，也会结束本程
- 打破个人最佳后，下一局会有一辆半透明 PB 幽灵车同屏陪跑；在首页可进入每日固定种子试炼或粘贴好友战书
- 每局同时追踪 3 项悬赏任务，达成即发赏金，结算后自动轮换
- 结算页可复制含本局轨迹的战书链接，或生成 1200×630 的战术战报 PNG
- 金币余额、个人最佳、每日最佳、幽灵轨迹、悬赏状态、已解锁车辆与改装等级保存在浏览器本地

## 特技与氮气

- **空翻**：腾空期间累计车身净角位移，每满 360°（留 0.42 rad 落地容差）记一圈；落地奖励 `12 × 圈数` 金币，并补发 `0.8s` 氮气。向前翻与向后翻按旋转方向分别播报。
- **完美落地**：滞空至少 `0.45s`，且落地时车身倾角与坡面切线夹角小于 `0.16 rad`。连击最高 `×5`，奖励 `5 × 连击` 金币、`1.6s` 氮气，并给予 `+1.2 m/s` 顺坡补偿。长跳落地角度偏差过大时连击归零。
- **单轮平衡**：后轮着地、前轮离地，且车身仰角高于地面坡度 `0.18 rad`。持续 `1.5s` 后每满 `1s` 奖励 `2` 金币，后轮迸发金色摩擦火花。前轮着地或腾空即重置。
- **氮气**：最多叠加 `3.5s`。开启时引擎推力 `×1.55`，即使不踩油门也维持 `60%` 巡航推力，极速上限由 `45` 提升至 `52 m/s`；镜头视野平滑拉远 `6%`，引擎基频与滤波截止频率上移，排气管喷射青白至琥珀的尾焰。HUD 以青色 `NITRO` 胶囊显示剩余时间。

## 四大生态赛段

每 `500m` 切换赛段，`2000m` 为一个循环；循环后地形起伏度继续增加。赛段边界前后各 `45m` 使用 `smoothstep` 平滑混合天空、远山、地面色板与光照。

| 距离 | 赛段 | 视觉与特殊地表 |
| --- | --- | --- |
| `0–500m` | 晨雾松林 · Alpine Dusk | 墨绿松林、琥珀破晓；标准抓地力与滚阻 |
| `500–1000m` | 高寒冰川 · Glacier Ridge | 冰蓝天空、覆雪山脊、迎面雪花；`18–32m` 冰封坡面，抓地力乘数降至 `0.52`，轮胎改装最多抵消 `45%` 打滑惩罚 |
| `1000–1500m` | 赤岩峡谷 · Red Canyon | 赤陶落日、横向风沙；波谷处 `14–24m` 泥泞洼地，抓地力 `0.78` 并附加滚动阻力，引擎与轮胎升级可显著降低陷车减速 |
| `1500–2000m` | 极夜山巅 · Night Summit | 墨蓝夜空、繁星与青绿极光；车头锥形大灯自动点亮，波谷上升热气流提供 `ay −3.8` 托举，辅助飞跃断崖 |

- 驶入新赛段时弹出赛段提示；每 `500m` 路标为双柱赛段门牌。
- 冰川冰面带冰青描边与结晶折线；峡谷泥地有深褐泥带与泥点飞溅；极夜段有琥珀/青绿上升流光。

## 局内道具

| 道具 | 生成规则 | 效果 |
| --- | --- | --- |
| 涡轮气瓶 `nitro` | 从第 2 个 Chunk 起，不与油桶重叠的爬坡前段约 `35%` 概率 | 氮气 `+2.2s`（上限 `3.5s`），青色粒子爆发与涡轮音效 |
| 磁铁信标 `magnet` | 含金币弧线的 Chunk 前方约 `25%` 概率 | 激活 `10s` 磁铁（上限 `12s`），`6.8m` 内金币加速飞向车身；车身带琥珀脉冲引力圈 |
| 金币 | 奇数 Chunk 的弧线 | 计入本程与累计余额 |
| 油桶 | 固定间隔 | 燃油 `+34` |

HUD 顶部同时显示当前 `STAGE 0X · 赛段名`，以及激活中的 `NITRO`、`MAGNET` 倒计时和 `COMBO ×N` 连击标签；无激活状态时自动隐藏。

## 幽灵车与同屏竞速

### 录制与压缩

- 每局在 `playing` 状态下每 `0.15s` 采样一次车身 `{ x, y, angle }`，最多 `1200` 帧（覆盖 3 分钟），结束时强制补上最后一帧落点。
- `x` / `y` 量化到 `0.1m`，`angle` 归一化后量化到 `0.01rad`；首帧存绝对量化值，后续帧存相对上一帧的差分，显著减小存档与分享码体积。
- 分享码使用 `RR2.` 前缀 + URL-safe Base64。若帧数超过 `240`，按固定 stride 抽稀并保留最终落点，码内携带 stride 以便回放还原时间轴；末尾带 FNV-1a 校验和。
- 任何损坏、截断、位翻转或字段越界的码都会安全解码为 `null`，不会抛异常或污染存档。

### 同屏表现

| 元素 | 规则 |
| --- | --- |
| PB 幽灵 | 常规赛中加载 `save.bestGhost`；冰川青 `#89d8c8`，车体透明度 `0.32` |
| RIVAL 幽灵 | 战书挑战中加载对手轨迹；琥珀橙 `#f0b15e`，车体透明度 `0.32` |
| 终点呼吸态 | 幽灵回放抵达最后一帧后停在落点，透明度降至 `0.22` 并缓慢呼吸 |
| 悬浮铭牌 | `PB · 842m` / `RIVAL · 1120m`，实时显示玩家与幽灵行进差（`+14m` / `-23m`） |
| 终点残影旗 | 在幽灵最终距离处绘制半透明发光旗，标注 `PB` / `RIVAL` 与米数 |
| 超越高光 | 玩家首次跨越幽灵最终距离且目标 `≥80m` 时，播放双音阶、冲击波、震屏并提示「超越目标 · 刷新山脊领跑线！」 |
| 视野外雷达 | 幽灵离开左右边界且距离差在 `120m` 内时，在屏幕边缘绘制 `◀ PB -28m` / `RIVAL +35m ▶` 胶囊 |

幽灵车播放按本局已行驶时间采样相邻关键帧：位置线性插值、角度走最短弧、车轮按水平位移推算旋转。标准模式打破 `save.best` 后自动更新 `bestGhost`；每日试炼刷新 `dailyBest` 后自动更新 `dailyGhost`。

## 每日试炼与战书挑战

首页新增「每日试炼」与「战书挑战」两个入口。

### 每日试炼

- 以 UTC 日期（如 `2026-11-06`）做 FNV-1a 哈希得到非零 32 位种子；所有玩家当天的地形、冰面/泥地、涡流与道具分布完全一致。
- 官方车型为 `VEHICLE_ORDER[dailySeed % 3]`；无论是否解锁，当日试炼统一使用四项 `Lv.5` 公平规格，免费体验。
- 存档记录 `dailyDate`、`dailyBest`、`dailyFirstClaimed`、`dailyGhost`。UTC 零点后第一次进入首页或开始每日试炼时自动重置当日成绩与幽灵，累计金币与常规赛 PB 不受影响。
- 奖励：

| 条件 | 奖励 |
| --- | --- |
| 当日首次完赛且距离 `>150m` | `+40` 金币（每日一次） |
| 每次刷新当日最佳且距离 `>200m` | `+25` 金币 |
| 打破当日最佳 | 保存为当日同种子幽灵并显示「今日最佳」 |

### 战书挑战

- 打开 `#challenge=RR2...` 链接，或在首页粘贴挑战码，即载入对手轨迹。
- 挑战模式锁定战书的 `seed`：若对手来自每日试炼，使用相同官方车型与 `Lv.5` 公平规格；若来自常规赛，使用玩家当前车库载具与改装。
- 对手以 `RIVAL` 幽灵同屏竞速，终点距离即战书目标。结算时 `finalDistance > rival.distance` 显示 **「挑战成功 · 击败对手」**，额外奖励 **`+35` 金币**。
- 结算页「复制战书链接」会把本局轨迹重新编码为完整 URL；收到链接的好友打开后会在完全一致的地形上同屏竞速。

## 单局悬赏任务

每局携带 3 项悬赏，来源为 6 类模板；同类任务不会同时出现。目标值与奖励随 `completedMissions` 每完成 5 项提升一档：

| 类型 | 目标档位 | 奖励 | 计数来源 |
| --- | --- | --- | --- |
| `distance` 长途奔袭 | `300 / 600 / 1000m` | `35 / 50 / 65` | 本局最远距离 |
| `flips` 空中转体 | `1 / 2 / 3` 圈 | `40 / 60 / 75` | 落地时结算的完整 360° |
| `perfect` 完美落地 | `2 / 3 / 4` 次 | `40 / 55 / 70` | 完美落地成功次数 |
| `coins` 金币矿脉 | `18 / 32 / 50` 枚 | `30 / 42 / 55` | 拾取的金币道具数 |
| `wheelie` 单轮平衡 | `2 / 4s` | `45` | 本局累计后轮平衡时间 |
| `stage` 深入秘境 | `500 / 1000m` | `50 / 80` | 驶入高寒冰川 / 赤岩峡谷 |

局内达成后立即发放赏金，播放琥珀色提示音与「悬赏达成 · 任务名」Toast；本局结束（`endRun`）时自动把已完成任务替换为新任务，未完成任务的进度清零。首页右侧「悬赏看板」、暂停面板与结算面板同步展示进度条。

## 战术战报

结算页新增「生成战术战报」与「复制战书链接」。

- 战报为固定 `1200 × 630` 的 Canvas，背景取自本局最远抵达赛段的渐变天空、视差山脊、太阳/极光、胶片颗粒与 Alpine Dusk 边框。
- 视觉中心用 `VehicleRenderer` 绘制本局载具（`#07` / `#12` / `#88`）的高清侧视涂装；左侧数据栏展示最终距离、纪录徽章、本程金币、空翻、最高完美连击、悬赏收益与四个赛段徽章。
- 底部铭牌包含 `RIDGE RUN · 山脊冲刺`、日期、模式、种子编号与挑战码摘要。
- 「下载 PNG 战报」通过 `<a download="ridge-run-XXXXm.png">` 导出；「复制挑战链接」与结算页共用剪贴板逻辑，失败时自动回退到 `execCommand` 文本框复制。

## 车库

首页「整备车库」或结算页「升级车辆」进入车库，也可按 `G` 打开。

| 载具 | 解锁条件 | 特点 |
| --- | --- | --- |
| `#07` 阿尔卑斯拉力车 | 默认 | 质量 150 · 双轮 · 均衡好上手 |
| `#12` 山脊轻骑 | 350 金币或最佳 600m | 质量 105 · 双轮 · 空翻扭矩 6.8，空中极灵活 |
| `#88` 极地重卡 | 900 金币或最佳 1200m | 质量 245 · 三轴六轮 · 抗翻稳定 |

每辆车有引擎、悬挂、轮胎、油箱四项独立改装，每项 10 级：

- 引擎：推力 `+8% / 级`
- 悬挂：弹簧刚度 `+4.5% / 级`，阻尼 `+6.5% / 级`
- 轮胎：抓地力 `+7% / 级`
- 油箱：容量 `100 + (level - 1) * 6`，油耗 `-4% / 级`
- 升级费用：`Math.round(20 * 1.42^(level - 1))`

## 本地开发

需要 Node.js 18+。

```sh
npm install
npm run dev       # Vite 开发服务器，默认 http://localhost:5173
npm run build     # tsc 类型检查 + 生成 dist/ 静态产物
npm run preview   # 本地预览构建结果
```

`vite.config.ts` 使用 `base: "./"`，`dist/` 可直接部署到 GitHub Pages、 itch.io 或任意静态托管目录。

推送到 `main` 后，`.github/workflows/deploy.yml` 会自动执行 `npm ci && npm run build`，并通过 GitHub Pages Actions 发布 `dist/`；仓库本身不需要提交构建产物。

### 存档兼容

`ridge-run-v2` 新增字段为 `bestGhost`、`dailyDate`、`dailyBest`、`dailyFirstClaimed`、`dailyGhost`、`missions` 与 `completedMissions`。

- 旧 `ridge-run-v2` 存档会自动补齐新字段，保留原有金币、常规赛最佳、已解锁车辆与全部改装等级。
- 旧 `ridge-run-v1` 存档继续走迁移：继承 `best` 与 `coins`，初始化车库后写入 `ridge-run-v2`。
- 损坏的幽灵记录（版本、mode/seed 不一致、帧数非法、坐标越界）会被丢弃为 `null`；非法悬赏会按当前完成数重新生成，避免坏档导致发车失败。
