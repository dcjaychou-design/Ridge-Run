## 核心特色

- **四大生态循环山脊**：每 `500m` 依次穿过晨雾松林、高寒冰川、赤岩峡谷与极夜山巅，`2000m+` 后地形起伏加剧并累计标注 `STAGE 05+` 多周目阶段。
- **物理悬挂与空中特技**：多轮悬挂刚体物理支撑车轮/底盘/车顶真实碰撞；通过 360° 空翻、贴坡完美落地连击、持续抬头单轮行驶赚取金币与氮气。
- **同屏幽灵与异步竞速**：自动录制个人最佳（`PB`）幽灵同屏陪跑；支持 UTC 每日固定种子试炼、`RR2.` 战书链接对抗，以及导入/导出内嵌战书数据的 `1200×630` 战术战报 PNG。
- **车库成长与局内悬赏**：三款定位鲜明的载具搭配四项 10 级改装，每局同步追踪 3 项三档进阶悬赏合约。
- **高分屏缓存与低功耗循环**：离屏分帧缓存远景与岩纹、量化复用云层与 20Hz 极光，暂停与弹窗覆盖时冻结后台渲染与挂起音频。

### 本地开发与部署

需要 **Node.js 22.18+**（CI 与生产环境推荐 Node 24 LTS）。

```sh
npm install
npm run dev       # 启动 Vite 开发服务器（默认 http://localhost:5173）
npm test          # 使用 Node 原生测试运行器执行 tests/*.test.ts（无额外测试框架依赖）
npm run build     # 执行 tsc 严格类型检查并输出 dist/ 静态产物
npm run preview   # 本地预览生产构建
```

- **便携部署**：`vite.config.ts` 使用 `base: "./"` 与 `assetsInlineLimit: 0`，构建出的 `dist/` 可直接放到 GitHub Pages、itch.io 或任意子目录静态站点；同时提供 `public/icon.svg` 与 `public/manifest.webmanifest`。
- **自动发布（CI）**：推送到 `main` 分支后，[`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) 会自动运行 `npm ci && npm test && npm run build`，并将 `dist/` 部署至 GitHub Pages。

## 游戏机制与数值规则

### 车辆物理与脱困

- **发车平坡**：起点配有一段 `2.5m` 平缓发车区，三款载具按真实车轮半径与悬挂行程贴坡停放，防止开局后溜或弹跳。
- **自然倒车**：倒车无硬编码极速上限；推力为引擎基础值的 `0.42×`，受倒挡传动阻尼自然制约，松开刹车靠滚阻与风阻滑停；燃油归零后引擎熄火，不再提供倒车及氮气推力。
- **接地与卡死保护**：车身底盘与保险杠触地同样计入接地，可用于落地判定、二次起跳及阻断极夜上升气流。接地且持续踩油门无进展超过 `4s`（且燃油 `> 15`）将消耗 `15` 点燃油自动退回安全坡面；车身大倾角倾覆接近静止超过 `2.2s` 时直接触发翻车结算，避免软锁。

### 特技与氮气

| 机制 | 触发条件 | 奖励与效果 |
| --- | --- | --- |
| **飞跃评级** | 滞空超过 `0.35s / 0.8s / 1.5s`（1 / 2 / 3 档） | 落地奖励 `1 / 3 / 6` 金币并触发地面冲击光效 |
| **空中转体（空翻）** | 腾空期间累计净角位移达 `2π - 0.42 rad` 整数倍 | 落地按净旋转圈数发放 `12 × 圈数` 金币并充能 `0.8s` 氮气 |
| **完美落地** | 滞空 `≥ 0.45s` 且落地夹角 `< 0.16 rad`（最高 `×5` 连击） | 奖励 `5 × 连击` 金币、`1.6s` 氮气，并沿当地坡面切线给予 `+1.2 m/s` 加速补偿 |
| **单轮平衡** | 仅后轮接地且车身仰角高于地面坡度 `0.18 rad` | 持续 `1.5s` 后每满 `1s` 奖励 `2` 金币并迸发金色火花；前轮落地或腾空重置 |
| **涡轮氮气 `NITRO`** | 空翻、完美落地、或拾取氮气瓶（叠加最高 `3.5s`） | 推力 `×1.55`、极速提升至 `52 m/s`、免油门保持 `60%` 巡航推力、视野额外拉远 `6%` |

### 四大生态与多周目

每 `500m` 切换一个生态，边界前后各 `45m` 使用 `smoothstep` 平滑混合天空、远景、地面调色板与连续植被/岩纹/轮胎印权重（`detailMix`）。每 `2000m` 完成一轮循环后，地形起伏幅度在接下来 `140m` 内平滑提升。

| 距离 | 赛段 | 地形特征与物理机制 |
| --- | --- | --- |
| `0–500m` | 晨雾松林 · Misty Pines | 标准抓地力与滚动阻力 |
| `500–1000m` | 高寒冰川 · Glacier Ridge | 每段含 3 处 `18–32m` 结冰坡面（基础抓地降至 `0.52`）；轮胎改装最高抵消 `45%` 惩罚 |
| `1000–1500m` | 赤岩峡谷 · Red Canyon | 谷底分布 3 处 `14–24m` 泥泞洼地（抓地 `0.78`、附加阻力）；引擎与轮胎升级可助推脱困 |
| `1500–2000m` | 极夜山巅 · Night Summit | 自动点亮锥形车头大灯与地面光池；波谷 2 处上升热气流提供 `ay -3.8` 垂直托举 |

驶入 `2000m+` 后，顶部与门牌阶段号累计递进为 `STAGE 05+`，赛段弹窗同步标明周目数与地形难度提升提示。

### 局内道具

| 道具 | 分布规则 | 作用效果 |
| --- | --- | --- |
| **金币** | 奇数 Chunk（`1, 3, 5...`）随机弧线生成 `3–5` 枚 | 计入本程金币与累计余额 |
| **油桶** | 第 `2` 个起每 `4` 个偶数 Chunk（`4k + 2`），与奇数金币带错开 | 回复 `+34` 燃油（不超过当前油箱上限） |
| **涡轮气瓶 `nitro`** | 从第 `2` 个 Chunk 起于无重叠安全空段约 `35%` 概率生成 | 立即叠加 `+2.2s` 氮气并伴随尾焰粒子 |

### 车库载具与改装

首页点击「整备车库」、结算页「升级车辆」或按 `G` 可随时打开车库。**每日试炼与每日战书**期间固定使用官方指定车辆与全项 `Lv.5` 公平规格，此时车库内会提示选车改装仅对常规模式生效。

| 载具 | 解锁条件 | 定位特性 |
| --- | --- | --- |
| `#07` 阿尔卑斯拉力车 | 初始解锁 | 质量 `150` · 双轮 · 重心均衡、全赛道万金油 |
| `#12` 山脊轻骑 | `350` 金币或个人最佳 `600m` | 质量 `105` · 双轮 · 空翻扭矩 `6.8`，极易连续翻滚 |

四项改装每项最高 `Lv.10`，当前为 `L` 级时升至下一级花费 `Math.round(20 * 1.42^(L - 1))` 金币：

- **引擎（ENGINE）**：推力 `+8% / 级`
- **悬挂（SUSPENSION）**：弹簧刚度 `+4.5% / 级` · 阻尼 `+6.5% / 级`

### 单局悬赏合约

每局固定携带 3 项不同类的悬赏，进度随完成总数 `completedMissions` 每满 5 项自动升档（Tier 0–2）；局内达成立即发赏金并写盘保存，本局结算或重新发车时轮换新合约。

| 类型 | 三档目标 | 对应赏金 | 说明 |
| --- | --- | --- | --- |
| `distance` 长途奔袭 | `300 / 600 / 1000m` | `35 / 52 / 70` | 单局最高有效行进距离 |
| `flips` 空中转体 | `1 / 2 / 3` 圈 | `40 / 60 / 75` | 落地结算的完整 360° 圈数 |
| `perfect` 完美落地 | `2 / 3 / 4` 次 | `40 / 55 / 70` | 完美落地成功次数 |
| `coins` 金币矿脉 | `15 / 28 / 42` 枚 | `32 / 48 / 65` | 单局拾取金币道具数 |
| `wheelie` 单轮平衡 | `2 / 3.5 / 5s` | `35 / 50 / 70` | 单局累计触发后轮平衡时长 |
| `stage` 深入秘境 | `500 / 1000 / 1500m` | `45 / 65 / 90` | 驶入高寒冰川 / 赤岩峡谷 / 极夜山巅 |

### 镜头视野（FOV）

- **基准缩放**：`baseScale = viewportWidth / cameraWidth`（默认 `36m`，支持 `28–52m` 步进调整与 `32 / 36 / 41 / 46m` 快捷预设），从手机竖屏到超宽屏一致呈现设定视角宽度。
- **动态缩放**：随车速最高再拉远 `10%`，氮气开启时额外拉远 `6%`；HUD 实时换算显示当前实际可视宽度（米），暂停面板同步对照显示基准与当前视野。

## 幽灵竞速、每日试炼与战书

### 同屏幽灵与 `RR2.` 分享编码

- **录制与压缩**：以 `0.15s`（`6.7Hz`）记录 `{ x, y, angle }`；超过 `1200` 帧（3 分钟）时自动对奇数样本抽稀并将 `stride` 翻倍，在严格预算下不丢终点时机。位置量化至 `0.1m`、角度归一化后量化至 `0.01rad` 并采用差分编码。
- **分享码防伪**：`RR2.` URL-safe Base64 编码最多携带 `240` 帧（新版 `v3` 头部含 `durationMs` 并保留最终帧），尾部带 FNV-1a 校验和并兼容旧 `v1`/`v2` 解码；读档与解码统一校验合理速度包络与最大里程（`250,000m`）。
- **视觉元素**：常规赛加载冰川青 `PB` 幽灵，战书加载琥珀橙 `RIVAL` 幽灵；冲过终点线呈 `0.22` 呼吸态停驻，首次在整米超越目标（目标 `≥ 80m`）触发冲击波与震屏高亮；当幽灵距离差在 `120m` 内且离开屏幕时，四周边缘会展示 `◀ / ▶ / ▲ / ▼` 方向胶囊且不与车体铭牌重合。

### 每日试炼与战书挑战

- **每日试炼**：每日按 UTC 日期（如 `2026-11-18`）通过 FNV-1a 生成非零种子决定当天地形、道具与官方车型（统一 `Lv.5` 公平规格）。当日首次完赛 `> 150m` 奖励 `+40` 金币，每次刷新今日最佳 `> 200m` 奖励 `+25` 金币。跨 UTC 零点结束的当前局保留结算供导出战报/战书，返航或开新局时切换至当日新榜单。
- **好友战书**：支持 URL `#challenge=RR2...`、首页粘贴挑战码，以及直接选择战报 PNG 导入对决。
  - **每日战书**：完全锁定原战书 UTC 日期、种子、官方车型与 `Lv.5` 规格。
  - **常规战书**：在标准地形（`seed = 0`）使用挑战者当前车库车型与改装应战，击败对手额外奖励 `+35` 金币；若打破个人常规赛纪录，同步更新 `save.best` 与 `bestGhost`。

### 战术战报 PNG

结算页生成 `1200×630` Canvas 战报：背景复刻本局最远抵达赛段的天空、四层山景与前景松林，中心绘制载具高清侧视涂装，左侧栏集中呈现里程、特技、幽灵胜负与赛段足迹（多周目额外标明周目数）。导出 PNG 时自动把完整 `RR2.` 战书码写入 `tEXt` 元数据块（`ridge-run-challenge`），好友导入该图片即可还原整场幽灵竞速。

## 山脊公报（内建公告系统）

项目内建「山脊公报」（数据位于 [`src/notices.ts`](./src/notices.ts)），用于在游戏首页展示版本更新日志与规则公告：

- **非打扰提示**：仅在 `save.lastSeenNoticeId !== LATEST_NOTICE_ID` 时于首页右上角亮起未读呼吸红点，不自动弹窗打断。
- **双页签与焦点管理**：支持「更新日志（`update`）」与「山脊公告（`bulletin`）」切换及置顶排序；有未读时优先切到最新公告所属页签；支持 `Tab`、`←/→`、`Enter`、`Esc` 全键盘导航与焦点回落还原。
- **维护方式**：只需在 [`src/notices.ts`](./src/notices.ts) 的 `NOTICES` 数组顶部新增唯一 `id` 条目，前端打包即生效，`LATEST_NOTICE_ID` 会自动指向首条记录。

### 性能设计、节能策略与实测数据

1. **分级缓存与分帧调度**
   - `MountainRenderer` 对四层高分屏远景（最高 `2×`、单层像素预算 400 万）使用尺寸预留与色调轮换刷新，避免同一帧重建四张大图。
   - `StrataCache` 按世界坐标 `8m` 分块缓存九层岩纹（最多 `24` 块），仅在种子或区间变更时失效。
   - `SkyRenderer` 将缓慢极光节流至 `20Hz` 复用光场，并对云层颜色进行量化重绘复用同尺寸画布；`VehicleRenderer` 与 `ItemRenderer` 在 `document.fonts.ready` 后自动清空并重绘高清贴图缓存。
2. **界面零冗余写入**
   - `HudController` 对所有文本和可见性状态做差值比较；`MissionBoard` 跳过被遮挡隐藏的看板 DOM 重建；HUD 不与 Canvas 叠加不必要的高代价全屏清空（主天空已完整覆盖不透明画布）。
3. **暂停冻结与低功耗循环**
   - `main.ts` 使用独立 `sceneTime` 与按需刷新调度：暂停期间彻底定格粒子与景物动画；页面隐藏时挂起 Web Audio 上下文；暂停、结算粒子落定后、系统开启 `prefers-reduced-motion` 以及车库/公告/战书等全屏弹窗覆盖时自动停止无效背景帧重绘。

### 本地存档与异常容错

- **主存档（`ridge-run-v2`）**：记录 `best`、`coins`、`muted`、`cameraWidth`、`selectedVehicle`、`unlockedVehicles`、`upgrades`、`bestGhost`、`dailyDate`、`dailyBest`、`dailyFirstClaimed`、`dailyGhost`、`missions`、`completedMissions` 与 `lastSeenNoticeId`。
- **兼容与自动修复**：兼容自动迁移旧版 `ridge-run-v1`；字段越界或异常（如 `cameraWidth < 28` / `> 52`、无效车辆/等级、`bestGhost.distance > best` 或 `dailyGhost.distance > dailyBest`）会被夹紧或重置，并记入 `repairedFields` 通过 Toast 告知玩家。
- **损坏备份与只读降级**：无法解析的损坏 JSON 会先备份到 `ridge-run-v2-backup` / `ridge-run-v1-backup` 再重置；若读取被浏览器拦截或备份写入失败，则锁定只读内存会话避免覆盖原有存档数据。
